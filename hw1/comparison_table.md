## Обоснование оценок

> **Важно о методе.** Практически проверен только Claude Code (на нём выполнены все ДЗ). Оценки Bolt.new, Lovable и Cursor — экспертные, на основе публичной документации и общеизвестных свойств инструментов, а не собственных замеров. Тарифы меняются, поэтому актуальные цены нужно проверять на сайтах сервисов.

- **Bolt.new и Lovable (контекст 2, безопасность 2).** Проект и код находятся в облаке сервиса, локальные файлы агенту недоступны. Скорость первой версии интерфейса высокая (5), но качество среднее (3): быстро получается демо, сложнее поддерживать тесты и нестандартную логику. Lovable интеграцией с GitHub и Supabase удобнее (3), чем Bolt.new (2).
- **Cursor (контекст 5, интеграция 5).** Индексирует весь проект, работает в привычном редакторе, поддерживает файл правил и MCP. Скорость хорошая (4) за счёт встроенных автодополнений. Безопасность средняя (3): код отправляется на серверы сервиса, есть настройки приватности.
- **Claude Code (контекст 5, качество 5).** Видит всю папку проекта, читает любые файлы, сам запускает тесты, сборку и `npm audit`, исправляет ошибки по их выводу. Скорость ниже (3): многошаговая работа с проверками занимает больше времени, чем одно автодополнение. Стоимость выше (2): оплата идёт по подписке или по токенам, при большой работе над проектом расход заметный. Безопасность средняя (3): код отправляется модели, но агент работает с правами пользователя и запускается в выбранном пользователем режиме разрешений.

Для российских пользователей отдельным критерием может быть доступность сервиса и соответствие требованиям к хранению данных. Для этого в курсе рассматриваются GigaCode и YandexGPT, а также on-premise развёртывание моделей (DeepSeek, Qwen). Для учебного проекта без персональных данных этот критерий не определяющий, поэтому в таблицу он не включён.


# Обоснование выбора

Выбран Claude Code.

## Ключевые факторы

1. **Локальные файлы и сквозной контекст.** Для ДЗ нужны документы `.docx`, `.md`, код, SQL и конфигурации в одной папке. Cloud-агенты такую работу не поддерживают.
2. **Самостоятельная проверка результата.** Агент сам запускает `tsc`, `vitest`, `vite build`, `npm audit` и исправляет ошибки по выводу. В ДЗ 6 так были найдены и закрыты 6 уязвимостей зависимостей, а после обновления Vitest исправлена ошибка типов в `vite.config.ts`.
3. **Качество на многошаговых задачах.** Проект включает код, тесты, SQL-миграции, CI и документы, которые должны быть согласованы между собой.
4. **Правила проекта.** Файл `CLAUDE.md` задаёт стек и запреты (ДЗ 2), и агент применяет их на каждой задаче.
5. **Практическая проверка.** Этот инструмент единственный, работу которого можно подтвердить логами, тестами и скриншотами.

## Честное замечание о выборе

По сумме баллов Cursor опережает Claude Code (24 против 22). Разница в два балла при экспертных оценках находится в пределах погрешности. Решающими стали пункты 2 и 5: автономный запуск проверок и наличие доказательств работы.

## Альтернативы и почему не подошли

| Вариант | Почему не выбран |
|---|---|
| Bolt.new | Проект живёт в облаке, нет доступа к локальным документам, слабая поддержка тестов и CI |
| Lovable | Хорош для быстрого прототипа интерфейса, но ограничивает контроль над кодом и структурой, нет работы с локальными файлами |
| Cursor | Близкая альтернатива: лучше по скорости и интеграции в редактор; уступает в автономном выполнении многошаговых задач с проверками. Может быть выбран, если важнее работа внутри редактора |
