# Описание проекта и стека

## Проект

HealthyBox — мобильное веб-приложение для заказа готовых наборов здорового питания на день или неделю. MVP: каталог рационов, детальное меню по дням, корзина с датой первой доставки, затем backend и CI/CD. Проект общий для ДЗ 2–6.

## Технологический стек

| Слой | Технология |
|---|---|
| Язык | TypeScript (strict) |
| UI | React 18, обычный CSS с переменными, mobile-first |
| Сборка | Vite |
| Тесты | Vitest, Testing Library, jsdom |
| Backend | Supabase (PostgreSQL, Auth, RLS) |
| CI/CD | GitHub Actions, Vercel |
| AI-агент | Claude Code, файл правил `CLAUDE.md` |

## Ключевые требования к коду и архитектуре

| Область | Требование |
|---|---|
| Стиль | PascalCase для компонентов и типов, camelCase для функций, отступ 2 пробела, строка до 100 символов |
| Архитектура | Экраны в pages, компоненты в components, чистая бизнес-логика в lib, данные и API в data |
| Деньги | Целые рубли, без дробных значений |
| Строгость | Запрещены any, @ts-ignore, мутация входных аргументов |
| Тесты | Для каждой функции из lib есть тест: нормальный случай, граничный случай, ошибка |
| Безопасность | Секреты только в .env, в репозиторий попадает .env.example |
